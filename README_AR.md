# ارفعلي — RAFLI 3.0

تطبيق iPhone لتجهيز الفيديو محليًا قبل النشر، مبني بـ SwiftUI وAVFoundation، ويدعم iOS 17 وما بعده.

- الاستوديو: اختيار فيديو من الصور أو الملفات، فحص البيانات الحقيقية، معاينة، اختيار طريقة التجهيز، ثم تصدير وتحقق من الناتج.
- فيديوهاتي: مكتبة دائمة للأصول والنتائج، مع تشغيل وحفظ ومشاركة وحذف وإعادة تجهيز.
- العربية والإنجليزية، RTL، مظهر النظام والفاتح والداكن وOLED، وحركة واهتزازات قابلة للضبط.
- الشعار هو الصورة الأصلية التي أرسلها المالك، دون تغيير الرسم أو الألوان أو قصّ الحواف.
- الدخول الخاص: `1v`.

## جودة الملف

يحافظ التطبيق على معدل المصدر حتى 60 إطارًا في الثانية، دون توليد إطارات وهمية. لا يكبّر الفيديوهات الصغيرة. الترميز H.264 مع AAC، أو الاحتفاظ بالتدفق الأصلي عند اختيار «بدون إعادة ترميز». تُقرأ بيانات الملف الناتج فعلًا قبل إضافته إلى المكتبة.

قد يعيد TikTok ترميز الفيديو بعد رفعه. المشاركة تتم بواسطة ورقة مشاركة iOS؛ لا يوجد زر رفع مباشر غير مُعدّ.

## البناء والتحقق

يشغّل GitHub Actions بناء iphoneos دون توقيع، ثم اختبارات محرك الفيديو والتنقل على المحاكي. ملف IPA يحتاج توقيعًا خارجيًا قبل تثبيته. راجع نتيجة الاختبارات لكل بناء قبل استخدامه.
